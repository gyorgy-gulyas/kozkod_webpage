Ki csatlakozhat?

Mindenki, akinek van szakmai tudása és szeretne állami nyílt forráskódú projektekhez hozzájárulni. A belépéshez felhasználónév, jelszó és TOTP 2FA szükséges.

Fejlesztő

Frontend, backend, full-stack, mobil — bármilyen területen. Kód írása, review, refaktorálás.

Tesztelő / QA

Funkcionális tesztelés, hibajelentés, tesztesetek írása, regressionális tesztelés.

IT-biztonsági mérnök

Sebezhetőség-keresés, biztonsági audit, biztonsági kód-review, bug bounty program keretében.

UX / UI tervező

Felhasználói élmény javítása, akadálymentesség, tervezési rendszer fejlesztése.

Technikai dokumentáló

API dokumentáció, fejlesztői útmutatók, README fájlok, wiki oldalak írása és karbantartása.

Fordító / lokalizáló

Felületek és dokumentáció fordítása, lokalizálása különböző nyelvekre és dialektusokra.

Architekt

Rendszer- és szoftverarchitektúra tervezése, technikai döntések meghozatala, komponensek közötti kapcsolatok kialakítása.

Üzleti elemző

Követelmények feltárása, folyamatelemzés, felhasználói igények és fejlesztői megvalósítás közötti híd.

Mit kapsz cserébe?

Állami tanúsítvány

Digitálisan aláírt, hivatkozható tanúsítvány. LinkedIn-en, önéletrajzban, közbeszerzési pályázatokon.

Pont- és szintrendszer

Bronz → Ezüst → Arany → Platina → KözKód Nagykövet. Nyilvános profilon megjelenítve.
